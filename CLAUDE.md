# Notes for Claude Code sessions

- This repository holds the LISA Slide Show (Atkinsonpoint) tool: SLD-*.TEXT
  sources, the PIX packs, `AtkinsonPoint_v1_1.dc42`, and the combined
  LISACom + Atkinsonpoint floppy. Everything is flat at the root.
- Commit directly to `main`; no pull requests, no tags here.
- The combined floppy (for example `LISACOM_1_7_ATKINSONPOINT_1_1.dc42`) is
  the same file that lives in GyroPilot/Apple-LISACom. When a new LISACom
  release ships, copy the new combined image here and commit it, keeping the
  older images.
- The full release and BBS publishing procedure is in `RELEASING.md` in
  GyroPilot/Apple-LISACom.
