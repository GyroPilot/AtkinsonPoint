11 note alert
Atkinsonpoint -- LISA Slide Show^L^L
Shows 680 by 300 one-bit pictures named *.PIX, in catalog order.^L^L
Named for Bill Atkinson, who wrote QuickDraw -- the graphics code
drawing this very screen -- and whose dithering algorithm turns
photographs into the black-and-white slides you are watching.^L^L
Inspired by Teslerpoint by Tom Stepleton, which showed that a Lisa
makes a fine slide carousel.^L^L
Bugs and ideas: post to LisaList2.

12 note alert
Making pictures^L^L
Pictures are made on a modern computer with lisapix.py, a Python
script distributed alongside this program -- search LisaList2 for
Atkinsonpoint to find both:^L^L
   python lisapix.py photo.jpg 1.PIX --fill^L^L
--fill crops the photo to fill the frame; --window letterboxes it
uncropped.^L^L
No script?  Write your own: the format is 680 by 300 pixels, one
bit each, 85 bytes per row, high bit leftmost, 1 = black, no
header -- exactly 25,500 bytes.^L^L
Send pictures to this disk as BINARY files named 1.PIX, 2.PIX ...
(zero-pad past nine) with LISACom's YMODEM receive, then choose
Look Again for Pictures from the Show menu.
