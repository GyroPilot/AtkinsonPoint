Insert a picture floppy and choose Copy Pictures from Floppy --^L

11 note alert
Atkinsonpoint 1.1 -- LISA Slide Show^L^L
Shows 680 by 300 one-bit pictures named *.PIX, in catalog order.^L^L
Named for Bill Atkinson, who wrote QuickDraw -- the graphics code
drawing this very screen -- and whose dithering algorithm turns
photographs into the black-and-white slides you are watching.^L^L
Inspired by Teslerpoint by Tom Stepleton, which showed that a Lisa
makes a fine slide carousel.^L^L
Bugs and ideas: post to LisaList2.

12 note alert
Making pictures^L^L
Made on a modern computer with lisapix.py, distributed alongside
this program -- search LisaList2 for Atkinsonpoint:^L^L
   python lisapix.py photo.jpg 1.PIX --fill^L^L
--fill crops to fill the frame; --window letterboxes uncropped.
No script?  The format is 680 by 300 pixels, one bit each, 85
bytes per row, high bit leftmost, 1 = black, no header --
exactly 25,500 bytes.^L^L
Send pictures over as BINARY files named 1.PIX, 2.PIX ...
(zero-pad past nine) with LISACom's YMODEM receive, or insert a
ready-made picture floppy and choose Copy Pictures from Floppy --
no cable needed.  Then Look Again for Pictures shows them.
